# 保护业务约定

服务面向博物馆的藏品、修复和公共服务场景。时间字段统一使用带时区的 ISO 8601 字符串，身份字段使用不可变字符串。后续模块应在保存业务变更时保留经办角色和发生时间，避免用展示层文本代替结构化状态。

健康检查只用于确认进程存活，不代表任何业务流程已经完成。数据文件若需要落盘，应放在运行时配置指定的位置（本服务为 `DATA_DIR`，默认 `.data/`，仅追加事件日志 `events.log`），测试不得依赖主机上的隐藏状态。

修复工单以事件日志为唯一事实来源：方案版本、会签、工序状态、冻结、领料与返工均不可就地改写，已开始的工序只能通过返工派生新一代实例；每次方案变更（含返工）必须与结构化风险说明同时落盘。
